# Database Extensions

## pgvector (0.8.2)

Provides vector data types and operators for similarity search.

- **Column**: `embedding vector(768)` on the chunk table
- **Index**: HNSW index for approximate nearest neighbor search
- **Operator**: `<=>` for cosine distance
- **Usage**: semantic search, duplicate detection, context scoring

Embeddings are generated by Ollama's `nomic-embed-text` model (768 dimensions).

## pg_trgm

Provides trigram-based text similarity functions.

- **Index**: GIN trigram indexes on chunk title and content
- **Operator**: `%` for similarity, `<->` for distance
- **Usage**: fuzzy text search, typo-tolerant matching

Trigram indexes power the "did you mean?" and partial match features in full-text search.

## Extension Versions

Both extensions come pre-installed in the `pgvector/pgvector:0.8.2-pg18` Docker image. No manual extension creation is needed — the migration handles `CREATE EXTENSION IF NOT EXISTS`.
