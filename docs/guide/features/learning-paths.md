# Learning Paths

Learning paths at `/learn` provide curated, ordered sequences of chunks for guided onboarding or topic deep-dives.

## Creating a Path

1. Navigate to `/learn`
2. Click "New Path"
3. Give it a title and description
4. Add chunks in the order they should be read
5. Optionally add notes between chunks for transitions

## Following a Path

When someone follows a learning path:
- Chunks are presented in sequence with navigation controls
- Progress is tracked (which chunks have been read)
- Transition notes provide context between chunks

## Use Cases

- **Onboarding** — guide new team members through architecture decisions, conventions, and key patterns
- **Topic deep-dive** — chain related chunks into a coherent narrative about a specific area
- **Incident review** — walk through the sequence of decisions and context around an incident
