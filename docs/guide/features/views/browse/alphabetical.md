# Alphabetical Index

The alphabetical view lists all chunks sorted by title with a letter navigation bar. Click any letter to jump to chunks starting with that letter.

## Features

- **Letter bar** at the top shows available letters (letters with no chunks are dimmed)
- **Chunk cards** display title, type badge, and tag list
- **Quick navigation** — useful for large knowledge bases where you know the chunk name
- **Sticky headers** — letter groups have sticky headers as you scroll

This view works best when your chunks have descriptive, consistent naming conventions.
