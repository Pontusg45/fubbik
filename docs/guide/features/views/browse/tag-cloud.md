# Tag Cloud

The tag cloud view visualizes the distribution of tags across your knowledge base. Tags are sized proportionally to their usage count — frequently used tags appear larger.

## Interactions

- **Click** a tag to filter the chunk list to only chunks with that tag
- **Hover** to see the exact chunk count
- **Color** comes from the tag's tag type, making it easy to spot domain clusters

## Use Cases

- Quickly assess what topics your knowledge base covers most
- Identify under-documented areas (small or missing tags)
- Discover unexpected tag distributions
