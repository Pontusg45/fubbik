# Compare

The compare view at `/compare` lets you view two chunks side by side with visual diffing.

## How to Compare

1. Navigate to `/compare`
2. Select two chunks using the search pickers
3. View the side-by-side comparison

## What's Compared

- **Content** — full markdown content with diff highlighting
- **Metadata** — type, tags, codebases
- **Decision context** — rationale, alternatives, consequences
- **Connections** — which chunks each is connected to

## Use Cases

- **Duplicate resolution** — compare two similar chunks to decide which to keep or how to merge
- **Before/after** — compare a chunk with its previous version
- **Alternative evaluation** — compare chunks marked as `alternative_to` each other
