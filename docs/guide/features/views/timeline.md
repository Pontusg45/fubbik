# Timeline

The timeline view at `/timeline` shows chunk creations and updates in chronological order, grouped by day.

## Date Ranges

Toggle between predefined ranges:
- **7 days** — recent activity
- **30 days** — monthly overview
- **90 days** — quarterly review
- **1 year** — long-term history

## What's Shown

Each entry shows:
- Chunk title and type
- Whether it was created or updated
- Timestamp
- Brief content preview

## Use Cases

- **Onboarding** — see what knowledge has been added recently
- **Review cadence** — check if knowledge is being maintained regularly
- **Activity audit** — understand patterns of knowledge creation over time
