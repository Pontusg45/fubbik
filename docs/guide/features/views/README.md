# Views

Beyond the standard chunk list and graph, fubbik offers several specialized views for different ways of exploring your knowledge base.

## In This Section

- [Kanban Board](./kanban.md) — drag-and-drop board organized by chunk type
- [Browse](./browse/) — alphabetical index and tag cloud views
- [Timeline](./timeline.md) — chronological view of chunk activity
- [Compare](./compare.md) — side-by-side chunk comparison
- [Compose](./compose.md) — dynamic aggregation and export of chunks
- [Density Map](./density.md) — knowledge distribution across file paths
- [Coverage](./coverage.md) — requirement coverage and traceability matrices
