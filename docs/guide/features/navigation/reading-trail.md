# Reading Trail

The reading trail sidebar shows chunks you've viewed during your current session, ordered by most recent.

## Features

- **Session-based** — the trail resets when you close the browser
- **Click to revisit** — click any entry to jump back to that chunk
- **Timestamps** — shows when you viewed each chunk
- **Deduplication** — viewing a chunk again moves it to the top instead of creating a duplicate entry

## Use Cases

- **Research sessions** — trace your exploration path through related chunks
- **Review workflows** — keep track of which chunks you've already reviewed
- **Context switching** — quickly return to a chunk you were reading before a detour
