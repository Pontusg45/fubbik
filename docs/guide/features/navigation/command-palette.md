# Command Palette

Press `Cmd+K` (or `Ctrl+K`) to open the command palette — a fuzzy-search interface for quickly navigating anywhere.

## Categories

The palette searches across multiple categories:

- **Recent Pages** — pages you've visited recently
- **Pages** — all application pages
- **Chunks** — search chunks by title
- **Tags** — jump to a tag's chunk list
- **Requirements** — find requirements
- **Plans** — jump to a plan
- **Codebases** — switch codebase context
- **Actions** — quick actions (new chunk, toggle theme, etc.)

## Usage

1. Press `Cmd+K`
2. Start typing to fuzzy-search
3. Use arrow keys to navigate results
4. Press `Enter` to select
5. Press `Esc` to dismiss

Results are ranked by relevance and recency. Recent pages appear first for zero-keystroke access.
