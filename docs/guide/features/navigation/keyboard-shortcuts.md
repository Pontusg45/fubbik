# Keyboard Shortcuts

Press `?` anywhere in the app to see the full shortcut overlay.

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `?` | Show shortcut help |
| `Cmd+K` / `Ctrl+K` | Open command palette |
| `Ctrl+O` | Quick open |
| `n` | Create new (context-aware) |
| `e` | Edit current item |
| `/` | Focus search |
| `f` | Toggle focus mode |
| `Esc` | Go back / close |

## Navigation

| Shortcut | Action |
|----------|--------|
| `j` / `k` | Scroll down / up in lists |
| `g` | Jump to top |
| `G` | Jump to bottom |

## Go-To Combos

Press `g` followed by a letter to navigate to a page:

| Combo | Destination |
|-------|------------|
| `g` then `d` | Dashboard |
| `g` then `c` | Chunks |
| `g` then `g` | Graph |
| `g` then `p` | Plans |
| `g` then `r` | Requirements |
| `g` then `s` | Search |
| `g` then `t` | Tags |
| `g` then `h` | Knowledge Health |

## Graph-Specific

| Shortcut | Action |
|----------|--------|
| `Tab` | Navigate to next connected node |
| `Shift+Tab` | Navigate to previous connected node |
| `Alt+Click` | Start path finding from clicked node |
