# Focus Mode

Press `f` to toggle focus mode — a full-screen view that hides the sidebar and navigation, letting you concentrate on the current content.

## Where It Works

Focus mode is available on:
- Chunk detail pages
- Chunk edit pages
- Graph view
- Document browser

## How to Use

- Press `f` to enter focus mode
- Press `f` again or `Esc` to exit
- While in focus mode, keyboard shortcuts still work (e.g., `e` to edit, `Cmd+K` for palette)

Focus mode is especially useful on the graph view for presentations and reviews where you want maximum screen real estate.
