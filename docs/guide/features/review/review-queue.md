# Review Queue

The review queue at `/review` shows all chunks and proposals awaiting human review.

## What Appears in the Queue

- **AI-drafted chunks** — chunks created by AI agents during implementation sessions
- **Pending proposals** — suggested changes to existing chunks
- **Unreviewed imports** — recently imported chunks that haven't been reviewed

## Actions

- **Approve** — accept the chunk or change as-is
- **Reject** — discard the proposal
- **Edit and approve** — modify before accepting
- **Bulk actions** — select multiple items and approve or reject in batch

## Filtering

Filter the queue by:
- Origin (manual, AI, import)
- Type (note, document, reference, etc.)
- Codebase
- Date range
