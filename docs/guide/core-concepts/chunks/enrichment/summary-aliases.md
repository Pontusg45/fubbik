# Summaries and Aliases

## Summary

A one-line description auto-generated by `llama3.2` that captures the chunk's core purpose. Summaries appear:

- In chunk list tooltips
- In search result previews
- In context exports as brief annotations

## Aliases

Alternative names the chunk might be known by. The AI examines the content and generates terms people might search for.

For example, a chunk titled "JWT Session Management" might get aliases like:
- "token-based auth"
- "session tokens"
- "bearer authentication"

Aliases expand search coverage — a search for any alias will surface the chunk even though the title doesn't match.

## Triggering Enrichment

- **Automatic** — runs on chunk create/edit when Ollama is available
- **Manual** — click "Enrich" on the chunk detail page
- **Bulk** — `fubbik enrich --all` from the CLI
- **Concurrency** — bulk enrichment runs 3 chunks at a time
